# Media Panel

Медиапанель для Windows в стиле XM4 Control: управление музыкой, обложки и альбомы, живая визуализация звука и клип без звука параллельно с музыкой.

## Что умеет
- Читает трек из системной медиа-сессии Windows (Spotify, Яндекс Музыка, браузер, любой плеер): плей/пауза, следующий/предыдущий, перемотка, громкость системы.
- Обложка, история альбомов, треклист альбома (Deezer). Клик по треку запускает поиск клипа.
- Клип: ищется сам по текущему треку, идёт без звука, стартует с текущей секунды музыки, ставится на паузу вместе с ней. Есть сдвиг ±0.5 с и кнопка синхронизации.
- Визуализатор настоящего звука (WASAPI loopback): столбцы, зеркало, круг, осциллограф, пики, индикаторы L/R. Цвет можно брать из обложки.
- Горячие клавиши: Space, ← →, ↑ ↓, M, V, C, /, F, P.

## Как получить exe
1. Залей эту папку в репозиторий на GitHub (ветка `main`).
2. Вкладка **Actions** → сборка `build-exe` (запускается сама после push, около 10 минут).
3. Готовый `MediaPanel.exe` лежит в **Releases → latest** (и в артефактах сборки). Установка не нужна.

Если что-то не заработало, рядом лежит `selftest.txt` со списком найденных и ненайденных зависимостей.

## Запуск из исходников
```
pip install -r requirements.txt
python main.py          # на Windows
python main.py --demo   # вымышленный плеер, для проверки интерфейса
```

## Замечания
- Нужны Windows 10/11 и интернет (клипы, Deezer).
- Некоторые клипы запрещают встраивание. Тогда плеер открывает обычную страницу ролика и показывает только видео. Реклама в клипе возможна, звук всегда выключен.
- Подписанного сертификата нет, поэтому SmartScreen или антивирус могут ругаться на exe.
- Если видео чёрное, запусти с переменной `QTWEBENGINE_CHROMIUM_FLAGS=--disable-gpu`.


## Что нового (v1.1)

- **Автосинхронизация клипа** — клип сам подтягивается к текущей позиции музыки, а через 2 секунды синхронизируется повторно (также после перемотки, паузы/плея и при дрейфе > 3 с). Включается в настройках.
- **Свой трек** — клик по любому другому треку в списке альбома/артиста включает клип с собственным звуком: плей/пауза, перемотка, громкость, mute, «К музыке». Музыка из плеера ставится на паузу, вернуться можно кнопкой «К музыке» или запуском музыки в плеере.
- **Второй дизайн «Liquid»** (клавиша **D** или кнопка в шапке) — клип на всю панель, поверх стеклянные карточки: сверху кнопки (поиск, история альбомов, другие клипы, скрыть интерфейс, поверх окон, на весь экран), альбом в левом углу с раскрывающимся треклистом, снизу — название, источник, длительность, прогресс, громкость, мини-визуализатор и сдвиг клипа. Клавиша **C** скрывает интерфейс.
